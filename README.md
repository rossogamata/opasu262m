# Наскрізний проєкт: система контролю гостьового доступу

Упродовж навчального курсу послідовно аналізуємо вимоги, проєктуємо та розробляємо навчальну інформаційно-комунікаційну систему контролю гостьового доступу на територію інституту. Кожне заняття розміщене в окремій директорії `LessonN_N`; матеріали подано у форматі `README.md`.

Система є наскрізним навчальним проєктом. Її вимоги та рішення формуються поступово на заняттях і мають узгоджуватися з потребами замовника. Приклад не є описом затверджених правил доступу конкретного інституту.
